# Findings (ranked)

Passive assessment only — no active exploitation performed. "Confirmed" = verified by direct header/code/status evidence without exploitation; issues requiring an exploit to prove are capped at "High" confidence and flagged for Phase 3.

| ID | Title | Severity | Confidence | Affected area | Evidence | Impact | Recommended fix |

## Confirmed positives (defensive controls working)
- Strong **HSTS** (2y, includeSubDomains, preload) [live].
- **No source-map exposure** (`.map` → 403); **no sensitive-file exposure** (`.env`/`.git`/etc → 307) [live].
- **API key never in client bundle** (`server-only` guard) [code]; API **enforces auth** (401 without key) [live].
- Cookie flags **httpOnly + secure + sameSite=lax** [code].
- **Production error masking**; API 500 leaks **no stack trace** [live].
- **No route-enumeration oracle** (nonexistent == existent = 307) [live].
- **No third-party trackers/analytics** (all *scripts* first-party; the only third-party request is the drei HDRI asset, SEC-11) [browser network log]; **no browser storage** used at all — `localStorage`/`sessionStorage` empty, no service worker [browser observation]; auth cookie **not readable by JS** (httpOnly verified: `document.cookie` empty) [browser].
- Dependencies **current** (Next 16.2.10 / React 19.2.4 / FastAPI ≥0.115); web build reproducible (lockfile).

## Not tested (withheld pending written active-test approval)
Input injection (SQLi/XSS/command) on API params & forms; the `from` open-redirect; auth-bypass/forced-browsing of gated routes; CSRF on server actions; rate-limit behavior under load; IDOR on `/products/{asin}` and `/my-products/{asin}`. See remediation-plan.md §"Phase 3 test plan".
